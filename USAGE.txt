## 3. ポリシー切り替え実行 (Policy Switcher)

学習済みのポリシー（双腕用、左腕用、右腕用）を読み込み、実行中に切り替えるには `policy_switcher.py` を使用します。

### 実行例

```bash
python policy_switcher.py \
    --task_name sim_many_cubes \
    --ckpt_dual ckpt/cooperation \
    --ckpt_left ckpt/independent_left \
    --ckpt_right ckpt/independent_right \
    --policy_class ACT \
    --kl_weight 10 --chunk_size 100 --hidden_dim 512 --dim_feedforward 3200
```

### 操作方法 (キーボード入力)

シミュレーション画面が表示されている状態でコンソール上でキーを入力します。

- **`1`**: 独立モード (Independent Mode)
  - 左腕ポリシーと右腕ポリシーが独立して各腕を制御します。
- **`2`**: 双腕モード (Dual Arm Mode)
  - 単一の双腕ポリシーが両腕を協調制御します。
- **`q`**: 終了

*注意: 実行には `aloha` 環境が有効化されている必要があります (`conda activate aloha`)。*
